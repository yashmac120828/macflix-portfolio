## 🚀 Quick Start (3 Steps)

### Step 1: Install & Setup (10 min)
```bash
npm install                              # Frontend
cd server && npm install && cd ..        # Backend

# Create server/.env with:
MONGODB_URI=mongodb://localhost:27017/macflix
EMAIL_USER=your-email@gmail.com
EMAIL_PASS=your_app_password_here
```

### Step 2: Start Servers (2 terminals)
```bash
# Terminal 1
cd server && npm start

# Terminal 2
npm run dev
```

### Step 3: Test
```
Visit http://localhost:5173
Fill form with your email
Check email for PDF quotation ✅
```
